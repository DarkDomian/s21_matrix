## Dependencies

You better to have `clang-format`, `cppcheck`, `valgrind`, `lcov`, `pkg-config` and `check`.

For fast install on ubuntu-based system do:
```bash
sudo apt-get -y install cppcheck valgrind lcov pkg-config check
```
